# Agentic-Desktop-Pet 对照优化记录

参考仓库：https://github.com/jihe520/Agentic-Desktop-Pet

## 适合吸收的方向

- 工具模块化：把待办、文件、浏览器等能力做成独立模块，再由输入工作流统一拦截。
- 桌宠状态外显：情绪、任务、RPG/生活属性都应该能被 UI 面板或对话命令查看。
- 前后端解耦思路：以后接 Godot 时，可以让桌宠导出 JSON 状态，由 Godot 读取，而不是互相硬绑。
- 主题/素材隔离：后续美术资源应独立成主题目录，避免和核心逻辑混在一起。

## 暂不直接搬的方向

- FastAPI 后端：当前 PyQt 桌宠已经是完整本地应用，直接加后端会增加启动复杂度。
- Cognee：依赖重，现有 `PersonaMemoryStore` 已经覆盖长期记忆和图谱联想，后续再评估。
- 整套 Godot UI：你的计划是自己在 Godot 里画地图和人物节点，不适合直接搬它的前端。

## 本次已落地

- 新增 `persona_pet/todo.py`：本地待办系统，保存到 memory meta 的 `todo_state`。
- 接入 `Live2DDesktopPet`：启动时初始化待办，退出和后台 flush 时保存。
- 接入聊天输入：输入待办命令会优先处理，不消耗 LLM 调用。

## 可用命令

- `创建待办 买牛奶`
- `新增待办 明天整理 Godot 地图节点`
- `查看待办`
- `完成待办 #1`
- `删除待办 #1`
- `清理已完成待办`
